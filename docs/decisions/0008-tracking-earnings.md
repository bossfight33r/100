# ADR-0008: Статистика append-only, доход как стратегия поверх снимков

**Решение.**
- `stats_snapshots` — только INSERT (триггеры SQLite запрещают UPDATE/DELETE). Источник: `youtube_api` или `manual`.
- Доход не хранится: `EarningsStrategy.compute(campaign, publication, latest_snapshot)`; сейчас `FlatRatePerK`, выбор через `strategy_for(campaign)` — место для порогов, бонусов, лимитов, ставок по платформам и дат кампании.
- Аналитика хуков — простые признаки (вопрос, число, первое лицо, интрига, длина) и lift средних просмотров; плюс корреляция score LLM ↔ просмотры.
- Рекомендации к промпту — файл `data/reports/prompt_recommendations_*.md`; production-промпт не меняется автоматически.

**Почему.** Сохраняем исходные данные — любую новую формулу дохода можно применить к истории задним числом.

**Отброшено.** Хранение итоговой суммы в публикации; автотюнинг промпта по статистике (малые выборки, риск деградации без ревью).
