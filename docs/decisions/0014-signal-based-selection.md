# ADR-0014: Выбор моментов по сигналам, без речи

**Контекст.** select искал моменты только LLM по транскрипту. Для игр (CS2), стримов и турниров это плохо: речи мало или нет, Whisper тратит время впустую, а «момент» виден по звуку и реакции зрителей, а не по тексту. Проект будет расти дальше клиппинга подкастов.

**Решение.**
- Кампания получает `selection: transcript | signals` и `transcribe: bool` (`false` допустим только с `signals`).
- `pipeline/signals.py`: каждый сигнал — ряд оценок 0..1 с шагом 0,5 с; ряды смешиваются с весами только доступных сигналов.
  - `audio` — RMS по окнам из `audio.wav`, превышение скользящей медианы за 60 с (сглаживание 2 с, мёртвая зона 1,5 дБ, 12 дБ → 1.0, тишина ниже -70 дБ не считается).
  - `heatmap` — YouTube «Most replayed» из yt-dlp (`info.heatmap`): медиана → 0, максимум → 1; плоская кривая отбрасывается.
- Окна: длина `clip_min + 0.25·(clip_max − clip_min)`, пик на 65% окна (завязка перед развязкой), границы не режут слова, окно ± полклипа гасится для следующих кандидатов, затем dedupe и top-N.
- ingest сохраняет безопасное подмножество info dict yt-dlp в `source.info.json` (название, канал, главы, heatmap; битые точки отбрасываются); прошлый файл удаляется перед загрузкой.
- `transcribe: false` пишет `audio.wav` и пустой транскрипт без Whisper. Субтитров в таком клипе нет.
- LLM в режиме signals не выбирает моменты, только пишет метаданные (render), получая главу и название видео в hook/reason.
- Совместимость кеша: config/input_keys кампаний `transcript` не изменились — идущие job не пересчитывают Whisper.
- Отдельно: `App.create_job` проверяет настройки LLM без сети (`llm_config_problem`) — пустой ключ ловится до ingest, а не на select после транскрипции.

**Почему.** Heatmap — бесплатный и сильный сигнал интереса зрителей, доступный на любом видео с достаточными просмотрами. Всплески звука ловят выстрелы, крики и рёв зала без моделей и GPU. Оба считаются за секунды на Mac M1.

**Отброшено / позже.** Новый этап `signals` (меняет JobStatus, БД, бота и API ради пары секунд вычислений). Килфид через OCR/нейросеть (Crispy) — зависит от HUD и версии Python. Демки CS2 (demoparser2/awpy) — точнее всего, но нужны `.dem` и запись через игру. Всплески чата стрима — сделано в ADR-0016. Проверка кандидатов мультимодальной моделью (Gemini видит видео). Каждый новый сигнал добавляется как ряд в `Signals.series` с весом в `WEIGHTS`.
