# ADR-0001: Корень репозитория = clipfactory/, Python 3.12 + uv

**Решение.** Корень git-репозитория и есть каталог `clipfactory/` из ТЗ (src-layout: `src/clipfactory`). Python 3.12 через `uv venv --python 3.12 .venv`, сборка hatchling, точка входа `cf`.

**Почему.** Репозиторий пустой, вложенный каталог добавил бы лишний уровень путей во всех командах. src-layout не даёт тестам случайно импортировать код без установки.

**Отброшено.** Вложенный `clipfactory/` (лишняя вложенность); poetry (uv быстрее и уже стоит в окружении).

**Мелкие отклонения от дерева ТЗ:** `log.py` (structlog + редактирование секретов; не `logging.py`, чтобы не путать со stdlib), `tests/__init__.py` для импорта хелперов из `conftest`.
