# ADR-0003: Ключи хранилища и локальный путь для ffmpeg

**Решение.** Этапы адресуют артефакты ключами `jobs/{job_id}/...` через `ObjectStorage`. ffmpeg нужен файл на диске, поэтому контекст этапа получает путь так: если хранилище реализует `SupportsLocalPath` (LocalStorage) — прямой путь, иначе `get_file` во временный каталог и `put_file` обратно. Запись в LocalStorage атомарная (tmp + rename). Checksum — sha256 с кешем по (size, mtime_ns).

**Почему.** Сегодня нет копирования гигабайтных исходников, а для S3 позже меняется только реализация хранилища.

**Отброшено.** Абсолютные пути в pipeline (тупик при переносе), `fsspec` (лишняя зависимость).
