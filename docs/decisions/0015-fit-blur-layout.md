# ADR-0015: Раскладка fit_blur для геймплея

**Контекст.** Кроп 9:16 из 16:9 оставляет ~32% ширины кадра. Для говорящей головы это нормально, для CS2 — нет: пропадают радар, килфид и сама цель, а лица для слежения нет (кроп стоит в центре).

**Решение.** Поле кампании `layout: crop | fit_blur` (+ `fit_zoom` 1–2).
- `fit_blur`: кадр вписывается в 1080×1920 (при `fit_zoom` > 1 — крупнее, края срезаются), фон — тот же кадр, уменьшенный до 1/8, размытый `boxblur`, растянутый и затемнённый `eq=brightness=-0.12`. Субтитры ложатся на размытую часть.
- Размеры считаются в Python (`filters.fit_dims`) по `ReframePlan.source_width/height` — без выражений с запятыми в filtergraph.
- reframe для `fit_blur` не запускает детекцию лиц и сцен: пишет план-заглушку по центру (render его не использует, но контракт `reframe.json` сохраняется).
- Ключи `layout`/`fit_zoom` попадают в config/отпечатки клипов только для не-дефолтной раскладки — существующие клипы `crop` не перерендериваются.

**Отброшено / позже.** Сплит-экран «вебка сверху, геймплей снизу» — нужна разметка зоны вебки на каждом стриме (разные позиции). Ревью-кроп (`cf review crop`) в `fit_blur` не действует.
