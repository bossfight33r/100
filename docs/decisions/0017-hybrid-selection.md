# ADR-0017: Гибридный выбор — речь + сигналы

**Контекст.** Стримеры и летсплейщики говорят во время игры: голый `transcript` не видит реакцию (крик, чат, пересмотры), голый `signals` не понимает смысл сказанного. Нужен режим, где LLM выбирает по речи, а сигналы подсказывают и взвешивают.

**Решение.** `selection: hybrid` (нужен `transcribe: true`).
- select строит те же ряды, что `signals` (`audio.wav`, `source.info.json`, `chat.json`), и пишет `signals.json`.
- В промпт каждого чанка дописываются пики итогового ряда в его диапазоне (`signals.peaks`: до 8, не ближе 20 с, со «ведущим» сигналом) с просьбой предпочитать клипы, чья кульминация совпадает с пиком, если речь вокруг тоже работает. Системный промпт не меняется.
- После подгонки границ оценка = 0,7·LLM + 0,3·100·сила сигнала в окне (`window_strength`: 0,7·пик + 0,3·среднее, по максимуму ряда), затем dedupe и top-N.
- ingest скачивает чат и для гибрида. Ключи гибрида в config/input_keys только у гибридных кампаний.

**Почему.** LLM остаётся главным (смысл, хук), а сигнал разрешает ничьи и поднимает моменты с реакцией. Доля 0,3 — стартовая; подстраивается по `cf signals` и статистике (`cf report`).

**Отброшено.** Отдельный LLM-проход только по пикам (дороже, теряет контекст чанка).
