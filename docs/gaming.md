# Игровой контент (CS2 и другие): от поиска до публикации

Коротко: ищем видео → режем по сигналам (звук, «Most replayed», чат) → вертикаль с размытым фоном и заголовком → ревью → публикация.

## 1. Какие исходники брать

| Исходник | Кампания | Почему |
|---|---|---|
| Записи стримов с орущим стримером / фейсвебкой | `cs2` (`signals`) или `hybrid`, если стример много говорит | звук + чат + пересмотры |
| Турниры с комментаторами (ESL, BLAST, PGL) | `cs2` | комментатор и зал кричат на хайлайтах |
| Готовые клипы Twitch / YouTube Clips | `stream_clips` (`whole`) | зрители уже выбрали момент |
| Подкасты/разборы про кс | `example` (`transcript`) | момент — в словах |
| Чистый геймплей без голоса | `cs2` | работает только звук выстрелов — слабее всего |

**Права.** Чужие видео на свои аккаунты — риск «повторного использования контента» и страйков. Безопаснее: исходники, разрешённые клиппинг-кампанией, свой контент или с согласия автора.

## 2. Найти видео

```bash
.venv/bin/cf discover "https://www.youtube.com/@<канал>/videos" --heatmap
#  🔥 — есть кривая «Most replayed» (лучший сигнал), · — нет
.venv/bin/cf discover "https://www.youtube.com/@<канал>/streams" --min-minutes 30
.venv/bin/cf discover "https://www.twitch.tv/<канал>/clips" --min-minutes 0
.venv/bin/cf discover "<ссылка>" --enqueue 3 -c cs2        # сразу в очередь
```

В Telegram-боте: `/discover <ссылка>` → кнопка с номером → кампания.

## 3. Автоматически

`config/watch.yaml` (шаблон — `config/watch.example.yaml`):

```yaml
sources:
  - url: https://www.youtube.com/@<канал>/streams
    campaign: cs2
    min_views: 20000
    max_new: 2
  - url: https://www.twitch.tv/<канал>/clips
    campaign: stream_clips
    min_minutes: 0
    max_minutes: 2
    max_new: 5
```

```bash
.venv/bin/cf watch --every 6h      # новые видео сами режутся; обработанные не повторяются
```

## 4. Как выбираются моменты

- **Звук**: громкость каждые 0,5 с против медианы за минуту — выстрелы, крик, рёв зала.
- **«Most replayed»**: где зрители пересматривают (YouTube, если у видео достаточно просмотров).
- **Чат**: всплеск сообщений в записи эфира, сдвинутый на 6 с назад (зрители пишут после момента).
- Веса: heatmap 0,6, чат 0,5, звук 0,4 — только среди доступных. Окно ~22 с (для 15–45 с), пик — на 65% клипа: сначала завязка, потом развязка.

Посмотреть, почему выбраны моменты:

```bash
.venv/bin/cf signals <JOB_ID>
```

Подстройка — константы в `src/clipfactory/pipeline/signals.py`: `WEIGHTS`, `PEAK_POSITION`, `target_duration`.

## 5. Как выглядит клип

`layout: fit_blur` — весь кадр 16:9 по центру (радар и килфид видны), сверху и снизу размытый фон; `fit_zoom: 1.2–1.4` — крупнее, но края срезаются. `title_overlay: true` — заголовок от LLM крупно сверху. Субтитры — только если `transcribe: true`.

## 6. Дальше как обычно

Ревью (`cf review` / бот / приложение) → `cf publish` → `cf track` → `cf report`.
